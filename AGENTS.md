# Repository instructions

## Our Picks requires human selection

Parts may be added to **Our Picks** only when a human explicitly selects those
specific parts. A catalog refresh, an agent recommendation, an audit, or a
general instruction to fix issues is not authorization to add or substitute a
pick. Do not add parts to `basicpart/src/data/other-components.json` based on
agent judgment. Preserve the selected C-number set unless the human explicitly
requests a membership change.

Correcting an existing pick's description, manufacturer identity, package,
tier, lifecycle guidance, or assembly restrictions is allowed within an
authorized maintenance task; it does not authorize adding another part.

Follow `basicpart/MAINTENANCE.md` for catalog collection, validation, and
publication. Preserve source evidence and distinguish manufacturer-confirmed
specifications from distributor metadata.
